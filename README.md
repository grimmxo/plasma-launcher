# Plasma Launcher

A game launcher for Linux (GTK4 + libadwaita) with your Steam library, the games in Heroic Games Launcher (Epic, GOG, Amazon), Minecraft: Java Edition, any other game you add by hand, and a built-in Steam store.

This repository describes Plasma; its source code isn't published here. Plasma is a personal project.

The logo, an infinity sign shaped like a game controller, and every icon in the app are Plasma's own, drawn as one matching set, so the app looks the same whichever icons the system has. The launchers' logos are the exception: they belong to Valve, Epic Games, GOG and Amazon, and are only used to say which launcher a game is from. Minecraft is shown with a plain block drawn for Plasma, not Mojang's mark. The Epic Games drawing comes from Simple Icons (CC0) and the Amazon one from Font Awesome Free (CC BY 4.0).

## Layout

The sidebar, the top bar and a thin border on the right and at the bottom are one frame all the way round the page, which has round corners at all four of its own. A switch at the top of the sidebar, an icon for each, moves between Library and Store, and the sidebar under it follows it: Home (with the sort button beside it) and the library's lists (Favourites, All games, the platforms, your collections) in the library, the store's lists and genres in the store. Under those are your friends. At the bottom left is you: your picture, name and what friends see you doing. Click it and it opens up, where it is, into your whole profile card, as wide as the sidebar: the banner and your picture grow into place and the rest comes out underneath. Click it again, click anywhere else or press Back and it shuts down to the strip. A friend's row in the list opens into their card the same way. The top bar holds the search (or a back button when a game's page is open) at its start, Plasma's name and mark in the middle, and the settings button at its end; the window has no buttons of its own (close it as your desktop closes windows, or with Ctrl + Q). Clicking the section you're already in goes back to its first page. Empty parts of the sidebar and top bar drag the window.

Behind everything is a blurred copy of game art that follows what you're looking at: the game under the pointer (or with keyboard focus) in the library, the store tile you hover, or the game whose page is open. It crossfades as it changes.

## Library

Where the games come from:

- **Steam, installed**: every Steam library folder (`libraryfolders.vdf` + `appmanifest_*.acf`). Proton, runtimes and redistributables are left out. The grid updates by itself when Steam installs or removes a game.
- **Steam, owned but not installed**: the rest of your Steam library, read from what Steam keeps on this computer (`appcache/packageinfo.vdf` says what the account has, `appcache/appinfo.vdf` what each thing is called). Nothing to set up. DLC, demos, soundtracks and tools are left out. A Steam Web API key is optional: with one (Settings → Connections), Plasma also asks Steam for the list, which adds play time for games Steam hasn't looked up here. The key is kept in `~/.config/plasma/steam-api-key`, readable only by you, and is only ever sent to Steam.
- **Heroic**: every game in Heroic Games Launcher's Epic, GOG and Amazon libraries and its sideloaded apps, installed or not. Nothing to set up. Heroic does the launching, without showing its window. Epic games are installed and removed by Plasma (see Game page, below); the other stores' are handed to Heroic.
- **Minecraft: Java Edition**, from wherever Minecraft's own launcher keeps it (`~/.minecraft`, or the Flatpak's folder). Play opens that launcher: see Minecraft, below.
- **Custom games** (emulators, itch.io, Lutris, Wine prefixes, scripts…): click **Add a game** in the sidebar, under the platforms, and give a name and a command (run through `sh -c`), and optionally a cover image. They're stored in `~/.config/plasma/games.toml`:

  ```toml
  [[game]]
  id = "18a3f0c2d1e"
  name = "Celeste"
  command = "'/home/me/Games/Celeste/Celeste'"
  ```

  A command that is just a path to a program runs from that program's folder.

Finding your way around:

- **Home**, the button at the top of the sidebar that stands apart from the rest, is where Plasma opens: the games that are ready to play, with the ones you played last above them.
- **Views** in the sidebar, under Home: Favourites, All games, Downloads (while anything is downloading) and Hidden (while anything is hidden). Then **Platforms**: one for each of Steam, Epic, GOG and Amazon that you have games from, and **Other**, for games you added yourself and anything else that isn't from one of those. **Add a game** is under them. Then one view per collection of your own. Each view but Home shows how many games it holds, and Plasma remembers the one you were on.
- **Sort**, the three-lines icon beside Home at the top of the sidebar, which opens a menu of the ways to sort, by recently played (the default), name, most played, recently installed, or size on disk. Favourites always come first, then games you can play, then the rest.
- **Search** is the magnifying glass at the left of the top bar: click it, press Ctrl + F or just start typing, and the box stretches out of the icon. It looks through every game, whatever view is showing, and folds away again once it's empty and you've clicked elsewhere, or pressed Escape. The store's search works the same way, except that typing on the store's own page doesn't start one.
- **Favourites and hidden games**: both are set on a game's page. A favourite gets a star on its cover. A hidden game only shows in the Hidden view.
- **Collections** are your own groups of games (Co-op, Backlog…), each listed in the sidebar. A game's page has a Collections row: tick the ones it belongs in, or type a new name. A collection is there for as long as a game is in it. Right-click one in the sidebar to rename it or delete it (its games stay), and a card's keyboard menu takes the game out of each one it's in and puts it into the first few others.
- **Big libraries.** A game's card, cover and all, is only made once it's in view or within a screen and a half of it; until then its place in the grid is an empty frame, which costs next to nothing to keep or to scroll past. A library of up to 400 games has all its cards before long, a few at a time while nothing else is going on; a bigger one keeps the 400 nearest the view and lets the rest go again. So thousands of games open as fast as a few dozen, and hold a fixed amount of memory. When the grid goes behind something else (a game's page, someone's profile, the Store) it waits a second and a half, in case you're straight back, then takes apart every card that wasn't in view, covers and all, and hands the memory back to the system; the cards that were in view are kept, so coming back finds the grid exactly as you left it, scrolled to the same place, and the rest are made again as they come near (in a library of up to 400, the rest of them too, a few at a time, while you're on it). Pictures elsewhere (the Store's rows, a profile page's showcase) do the same: one that goes off screen without having been in sight lets its picture go, and loads it again when it's back. Scrolled to the foot of 2000 games and then left, Plasma goes from about a gigabyte back to about a third of one.
- **Continue playing**, above the grid in Home and All games, is the three installed games you played last, as wide tiles: click one to play, right-click for its page.

The cards:

- The platform is marked in the top left of each cover with its logo (Steam, Epic Games, GOG, Amazon), or a computer for games you added yourself. The same logos mark the platforms in the sidebar.
- Hovering shows the game's name and a small play button. Clicking the card starts the game. While it runs, the card gets a green ring and the button becomes a stop button; Plasma asks before closing the game, then closes it and everything it started. This also works for games started from Steam or Heroic themselves.
- A game that isn't installed is greyed out with an install button. For a Steam game, Plasma asks where to put it and has Steam download it in the background (see Store, below). An Epic game is downloaded by Plasma too, with the tool Heroic ships for it. GOG and Amazon games are handed to Heroic, which offers to install them.
- A game that's downloading shows "Installing 42%" (or Updating, or Paused), how fast it's going and how long it has left, and a progress bar along the bottom of its cover. The **Downloads** view lists every one. Steam's are read from its manifests, and are Steam's to pause or stop; an Epic download's card button stops it, keeping what's been fetched.
- Right-click a card to open the game's page. The Menu key (Start on a controller) opens a small menu instead, with Play/Close/Install, **Game page**, favourite, hide, and the launcher's own actions.

Steam games can only be started by Steam, so it has to be running, and it shows its own windows while it starts one: a small "Launching" box, then anything the game needs first. The one that most looks like Steam opening is **Processing Vulkan shaders**, which brings Steam's main window up until it's done or skipped. To stop that, set **Compile shaders** under Steam in Settings → Connections to **Never** (or **In the background**, where Steam does it while nothing is being played). These are Steam's own two shader settings; Steam only reads them as it starts, so Plasma asks first, then closes Steam, changes them and starts it again in the background. The file it changes is Steam's `config/config.vdf`, and a copy of how it was is kept beside it as `config.vdf.before-plasma`. Plasma asks Steam to keep its main window closed (`steam -silent`) whenever it hands it anything.

## Connections

Settings → Connections lists each launcher Plasma takes games from: Steam; Epic Games, GOG and Amazon, which all come through Heroic Games Launcher; and Minecraft. For each one it shows whether it's on this computer, who's signed in to it, and how many games it holds, with a button to open it and two switches:

- **Games in the library**: leave a launcher's games out of Plasma without touching the launcher.
- **On my profile**: put that launcher on your profile card, as a small badge with its logo beside your picture (pointing at it says your name there; Steam's opens your Steam profile), for friends to see. The same switches are in the profile's editor. It's off until you turn it on. Steam's is a link to your Steam profile.

Steam has two settings of its own here. **Install games on** is the folder new games are downloaded into, with how much room its drive has. The choices are the library folders Steam already has (`steamapps/libraryfolders.vdf`); a drive Steam has never used has to be added once in Steam's Storage settings, and one that isn't plugged in can't be chosen. Until you choose, it's the folder with the most games in it. **Compile shaders** is described under Library, above.

Plasma doesn't sign in to the launchers itself. It reads what each one keeps on this computer, so signing in is done in Steam or in Heroic. Minecraft shows who's signed in to its own launcher, with a button to open it; once Plasma has an app id of its own, its Microsoft account is signed in to here instead (see Minecraft, below). The refresh button at the top looks again.

Some things come from Steam's own files with nothing to set up: the name and picture of the account signed in (the Friends page can use the picture as yours), and each game's **achievements**, shown on its page with the unlocked ones first. A game Steam has never looked at on this computer has none to show.

Settings → Controls lists these too.

| --- | --- | --- |
| Move between games | Arrow keys | D-pad or left stick |
| Play or install | Enter | A / Cross |
| Game page | Alt + Enter | X / Square |
| Game menu | Menu key or Shift + F10 | Start |
| Favourite | (in the game menu) | Y / Triangle |
| Back | Escape | B / Circle |
| Search | Just type, or Ctrl + F | |
| Close Plasma | Ctrl + Q | |
| Next or previous list | | Bumpers |

The window has no close button of its own: close it the way your desktop closes any window, or press Ctrl + Q.

The card with focus stays highlighted for as long as you're using the keyboard or a controller, and the highlight goes back to the pointer when you move the mouse. A controller only drives Plasma while its window is the active one, so playing a game doesn't move things around behind it. Steam can turn controller buttons into key presses when no game is in front; Plasma treats the two arriving together as one press.

## Game page

The game page has a banner right across the top that fades into the page, with the game's logo over it, a Play/Close/Install button (showing download progress while Steam is installing it), last played, play time, size and platform, and a star to make it a favourite. Under that:

- **Steam games** have the store description, their achievements, and these: Launch options and Proton version, which are set right there, with a switch each for GameMode, MangoHud and Gamescope where they're installed (see below); Properties (betas, cloud saves), Controller layout and Verify game files, which open Steam's own windows; Uninstall, which Plasma does itself (see below); and Browse local files, Screenshots (the folder they're saved in), Achievements (in your browser) and Store page (in Plasma), which don't touch Steam. A game that isn't installed only has the ones that make sense.
- **Heroic games** have a link to open Heroic, where the Wine version and launch options live, and one to browse the game's files. An installed Epic game also has Update, Repair and Uninstall, which Plasma does itself.
- **What's new**, on a Steam game's page: the last three things its makers posted on Steam, patch notes mostly, each opening to its text there on the page.
- **Minecraft** has who's signed in to Minecraft's launcher, its folder, and a link to the launcher, where its versions, settings and mods are. Once Plasma starts it itself, it also has Sign in or Sign out, the version and the memory.
- **Local games** have their launch options: name, command, environment variables, working folder, and switches for GameMode, MangoHud and Gamescope (each only if installed). Plasma records their play time in `~/.local/share/plasma/stats.toml`.
- **In Plasma**, for any game: a custom display name, cover and banner, the collections it's in, and a switch to hide it. These are kept in `~/.config/plasma/overrides.toml`, along with favourites.

**Uninstalling a Steam game**, from its page or the game menu, is done by Plasma, because Steam's own uninstall asks in a box of its own. Plasma asks instead, saying how much room it frees and which folder goes. It then removes Steam's note that the game is installed (`appmanifest_<appid>.acf`), the game's folder under `steamapps/common`, and its Workshop items. Everything in the folder goes, including anything added to it since, such as mods. The game's Proton folder (`compatdata`) is left alone, since saves can live there, and so is a folder two games share. Steam has to be closed while this happens, or it would put its note back and fetch the game again, so if it's running Plasma restarts it in the background, which closes any Steam game that's running. The game stays in your library, to install again.

**Launch options and the Proton version** of a Steam game are Steam's own settings, kept in its files: launch options in your account's `userdata/<id>/config/localconfig.vdf`, the Proton chosen for a game under `CompatToolMapping` in `config/config.vdf`. Plasma changes just those lines, checks that nothing else in the file reads differently, and keeps a copy of the file as it was beside it (`….vdf.before-plasma`). Steam only takes them in as it starts and writes its own copy back as it closes, so if Steam is running Plasma asks first, then closes it, makes the change and starts it again in the background, which closes any Steam game that's running. The Protons offered are the ones installed: Valve's, and any of your own under `compatibilitytools.d`. The GameMode, MangoHud and Gamescope switches are the same launch options, written for you: turning one on puts its program in front of `%command%`, and turning it off takes it out again, leaving the rest as it was.

**Epic games** are installed and removed with `legendary`, the tool Heroic itself uses and ships, pointed at the records Heroic keeps for it. So Heroic never opens, and afterwards has the game exactly as if it had installed it. Plasma asks first, saying where it goes (Heroic's install folder); the card and the page then show how far along the download is. Closing Plasma stops the download, and Install picks it up again. Update fetches a newer version if Epic has one, and says so on the row when its records already know of one; Repair checks every file and fetches again any that are missing or damaged. Uninstalling deletes the game's folder and leaves its Wine prefix, which is Heroic's. Heroic still does the first-run setup and the launching, and GOG and Amazon games are still installed by Heroic.

## Minecraft

Minecraft: Java Edition has a list of its own under Platforms in the library's sidebar, with who's playing over the game. Plasma doesn't install it: install it with Minecraft's own launcher as usual, and Plasma finds it in `~/.minecraft` (or `~/.var/app/com.mojang.Minecraft/.minecraft` for the Flatpak, `%APPDATA%\.minecraft` on Windows). A folder anywhere else that's laid out the same way, such as another launcher's modpack, is added with the folder button on that bar, and taken out again from its page.

**Play opens Minecraft's own launcher**, where you're signed in, and you press Play there. The versions, settings and mods are all the launcher's. Plasma spots the game running by its Java, which runs from the Minecraft folder, so the card shows it running, Close closes it, and Plasma counts its play time itself (the launcher doesn't). The bar shows the player name and picture of whoever's signed in to the launcher. Plasma reads only those from the launcher's `launcher_accounts.json`, and never its sign-in tokens.

**Starting the game from Plasma itself** is built too, but stays hidden until Plasma has an app id of its own. Microsoft only lets an app sign people in to Minecraft once it's registered with Microsoft and Mojang has approved it:

1. Make a directory to register apps in. A personal Microsoft account can't register apps by itself any more. Signing up for a free Azure account makes one; it asks for a card to check who you are, and registering an app costs nothing.
2. In the [Azure portal](https://portal.azure.com), under App registrations, make a **New registration**: any name, for personal Microsoft accounts, with no redirect address. On its **Authentication** page, switch **Allow public client flows** on.
3. Ask Mojang to approve the app for Minecraft, with the form Minecraft's help pages link to for new apps (it takes the Application ID).
4. Put its **Application (client) ID** in `~/.config/plasma/settings.toml` as `minecraft_app_id = "…"`. It isn't a secret.

With an app id set, Sign in appears on the Minecraft bar, the game's page and Settings → Connections. It shows a short code to enter at microsoft.com/link, so Plasma never sees your password, and keeps what it needs in `~/.config/plasma/minecraft-account.json`, readable only by you. Play then starts the game without the launcher. Plasma reads the chosen version's description in `versions/<version>/<version>.json` (a modded one together with the version it's built on), fetches from Mojang any files it lists that aren't there yet, and runs it with the Java Minecraft's launcher fetched into `runtime/`, or a system Java of the right version. The game's page then also has the version to play and how much memory it gets.

## Store

While the store is showing, the sidebar lists ways into it: Featured (a bit of everything), Top sellers, New releases, On sale and Coming soon, then Steam's genres. Each genre shows its top sellers, new releases, sales and upcoming games. It all comes from Steam's public store API, priced in your locale's country. Search finds any Steam game, and choosing a list clears the search. A game's page has its art, details and screenshots, plus:

- **Buy on Steam's website**: opens the game's page in your browser. Looking at a game never opens the Steam app, and buying happens on Steam's site.
- **Install**: for free games and ones you own. Plasma asks in its own box, which says where the game will go (the folder from Settings → Connections, or pick another of Steam's folders there and then), and Steam then downloads it with no window at all. Steam is restarted in the background to start the download, which closes any Steam game that's running, so the box says so first. The download then shows on the game's card and on its page in the store, where Install becomes Installing and then Play. (Steam has no command for this. Plasma leaves it the small note it keeps for a game whose download is under way, the `appmanifest` file, in the folder you chose, and Steam carries on from there when it starts. It works, but it leans on how Steam happens to behave.) A free game that isn't in your library yet is the one case where Steam shows: only Steam can add a game to your account, and the way to ask is `steam://install/<appid>`, which puts its install box up. Plasma waits until Steam's files show the game is yours, then carries on as above, which closes the box. It was up for about nine seconds when this was tried. Plasma counts a game as yours if Steam's files say the account has it, or if your Steam key says so. A game that isn't out yet has only the Steam's website button until it is, unless it's already yours (a preorder keeps Install, for preloading).
- **Play**: when it's already installed.

Cover art is cached in `~/.cache/plasma/art`, and loaded at the size it's shown. Newer Steam games publish their art under names that can't be guessed, so Plasma asks Steam's store API where it is and remembers the answers in `~/.cache/plasma/steam-assets.json`.

## Friends

See when friends are online and what they're playing, without Steam or any other account. It's off until you turn it on in Settings → Friends.

- **No sign-up.** Turning it on makes an identity on your computer and gives you a friend code. Send the code to a friend and add theirs; once you've each added the other, you see each other in the sidebar. If only one of you has, the other gets a request to accept or decline. Someone you've removed, or whose request you declined, doesn't come back as a request: add their code yourself if you change your mind.
- **Profile cards.** Click a friend in the sidebar and their row opens up, where it is, into their card: banner, picture, name, what they're playing and a few words about themselves (their bio, up to 190 characters). It opens downwards and the friends below it move down to make room; if it would run off the bottom, the list scrolls to keep it in sight. Yours is the strip at the bottom left and opens the same way, upwards. Only one card is open at a time: click it again, click anywhere else or press Back to shut it. Anyone with a banner has it behind their row in the sidebar too, and yours is behind the strip at the bottom left. Pick an animated GIF for either and it keeps moving, on your card and on your friends' screens. Nothing you pick is used as it is: Plasma makes a high-resolution GIF of it, and that's what's kept, shown and sent. If the picture isn't the shape of its frame (square for the picture, a wide strip for the banner), a window comes up first to place it: the part inside the frame, round for the picture, is what shows, and what's outside it is dimmed. Drag it about, and zoom in with the slider or the scroll wheel; "Use this" carries on, Cancel leaves things as they were. The GIF is up to 512 pixels square for the picture and 1500 by 525 for the banner, and never bigger than what it was made from. Where ffmpeg is installed it makes the GIF, choosing the colours from the whole picture (every frame of one that moves) and spreading them finely, so it stays close to the original; without ffmpeg Plasma makes it itself, more roughly. A GIF that moves keeps its frames, as many as are worth holding (fewer for a big banner), with none shown for less than a twentieth of a second on the picture or a fourteenth on the banner (quicker frames are run into the one before, so it runs as long as it did). Every GIF is under 10 MB: one that comes out bigger loses frames, then is made smaller, until it fits. A small JPEG still is kept too, for friends on a copy of Plasma from before this. The editor says "Making a GIF of it…" while that's going on, and then what came of it ("Made a 1500 × 525 GIF, 2.4 MB, 40 frames"); a big moving one can take half a minute. An animated WebP or PNG is taken the same way where ffmpeg is installed, which makes a GIF of it first; without ffmpeg it holds still. The file you pick can be any size a picture is likely to be: up to 96 MB, a GIF up to 4096 pixels each way and its first 480 frames, a still up to 120 million pixels. Past that Plasma says why and leaves things as they were, and it reads those limits from the file's first few bytes, before opening the picture itself. A moving picture costs next to nothing until it's looked at: only its first frame is read to begin with; the rest is read, away from the window's own thread, once the picture is somewhere it can be seen, made no bigger than it's shown there as it's read (a banner behind a row of the sidebar at half size or less), and let go of a couple of seconds after it's scrolled out of view or its page is left. With Reduce motion on, nothing but first frames is ever read. A GIF from a friend is only taken if it's no bigger than the ones Plasma makes, however small the file. The GIFs travel apart from the rest of the profile, so a friend on a copy of Plasma from before this still gets the still picture. A picture with see-through parts stays see-through, and is shown with nothing behind it but the card or page. (A GIF's pixels are either there or not, so soft edges come out hard.) Nothing is drawn round profile pictures: no ring, no shadow. Your profile is changed in its editor, which "Edit profile" on your card or your page opens (so does Settings → Friends → Your profile). Your card is its whole left side, top to bottom, and you change it by clicking it: the banner or the picture for another (Remove banner and Remove picture, beside the card, take them away), your name or your bio to write it again in a box that pops out beside it. Beside the card are the things that aren't on it to click. **Card colours**: a square that stands for your card, with a point in it for each of two colours. Drag the points about: the open card is the first colour up to where the first point is, the second from the second point on, and shades from one to the other along the line between them, so where you put them says where the shading starts, where it ends and at what angle it runs. A point close to the card's edge or middle, or level with or straight above the other, is put exactly there. Click a point, or its colour beside the square, to change the colour in a picker (a square for how strong and how bright, a strip for which colour, a box to type one in, and a few of the strongest colours from your banner and picture, as they were when the editor opened, to take at a click). "Swap" puts each colour where the other was, "Reset" puts the points back at the top and the bottom, and "None" goes back to the theme's own. The colours are shown exactly as you pick them, white as white; what's written on the card turns dark on light colours and stays white, with a soft shadow, on dark ones, so it always reads, and the banner's foot fades away into them whatever they are. **Connections**: a switch for each launcher your card can say you play on, for those that are signed in. Nothing is changed, or sent to friends, until you press Apply. Friends see your card in your colours, and you see theirs in theirs. Any image will do for the pictures: one that isn't the frame's shape is placed in it first.
- **Profile pages.** On an open card, clicking the picture opens that person's page (your own card has an "Edit profile" button under it too), which has room for more: their banner right across the top with their picture, name and their bio (the words about themselves on their card) over it; under that a bar; then the sections they've chosen, in the order they've put them: their favourite games, the games in their current rotation (the ones they're playing these days, as they choose them), the six they've played most recently, and the five they've played most. Nothing from Steam's own profile is on it (no achievements): it's only their games. **The bar** has as many things of their choosing on the left as they like, in a strip that scrolls along (with the wheel too) when there are more than fit: how many games they have, their play time, the game they played last, the one they've played most, how long they've played this week or this month, their longest session, how many days running they've played, and the game they've played most this week. Past a line down it on the right are the launchers they play on, each with its logo and their name there (Steam's opens their Steam profile). The last few of those are from the sessions Plasma notes of every game it sees running, whichever launcher started it, in `~/.local/share/plasma/sessions.toml`: when each started and how long it went on, kept for two months, and the longest ever. Plasma only sees what's played while it's open, so a session counts from when it was opened, or until it was closed. Yours is made from your own library, so it works with friends turned off too, as a page about you. Click the pencil beside "Favourite games" to choose up to six games for it; until you do, it shows your favourites. Clicking a game on anyone's page opens its page in your library if you have it, or the store's if Steam has it. The **Customise** button on your own page opens its editor, which sets it out: on the right, what can be changed; on the left, filling that whole side as the card does in the profile's editor, the page as it will come out, made of the page's own parts and keeping up with every change. Your name, picture and banner are your own there, and so is everything the editor changes; the games and numbers are made up (cards of one colour with names that aren't any game's), so the picture shows what each part looks like without waiting on your library. Nothing is changed for real, and nothing sent to friends, until you press Apply; Cancel, or closing the editor (Escape), leaves the page as it was. In both editors Cancel and Apply come up at the foot of the right side once you've changed something, stay there however far you scroll, and go again if you put everything back as it was. There you set, from the top: the banner (on or off), the page's colour (eight to pick from, or the theme's own), and a gradient of two colours of your choosing that its bars of play time, the bar under your name and the marks beside its sections shade between, in place of the one colour; the background, a picture or a video, or with neither a colour of your choosing; the bar, what's on it shown as chips to take off, wrapping from line to line, with an "Add widget" menu to add more; and the sections, each a row to drag up or down into the order you want, with an × to take it off and an "Add section" menu for the rest. Favourite games and Current game rotation list their games as chips, each with an × to take it out, and an "Add game" menu that searches your library (up to six in each; with no favourites chosen, your favourites are shown). The **background** is a picture of your own behind the whole page: choose any image there and Plasma keeps all of it as a GIF, up to 2560 by 1600 and under 10 MB, the same way it does the picture and banner. Or choose a video, or a GIF: Plasma never uses it as it is, but has ffmpeg make a copy that's light to play and small enough to send, 960 by 540, 15 frames a second, the first 20 seconds, no sound, 3 MB at most, with its first frame kept as a picture for whoever can't play it. It plays behind the page over and over for as long as the page is on screen; a few seconds after the page is left, its player is let go (tens of megabytes), and it starts again from the beginning when you're back; if you'd rather it stopped whenever another window is in front (a game, say), turn off **Animations when unfocused** under Settings → Appearance. With Reduce motion on it's the still picture, and friends who have that on aren't sent the video at all. Reading so small a video is cheap; what costs is the window being drawn again for every frame, which here comes to about a sixth of one processor core while you're looking at the page. A video needs ffmpeg installed to make it, and GTK's video player to show it (a copy of Plasma without one shows the still); without ffmpeg a GIF gives its first frame. It stays put while the page scrolls over it, shown as it is, with nothing over it. With the banner switched off the page starts at your picture and name, so you can show the background alone, the banner alone, or both, with the banner fading into the background. So you can keep the games you've chosen and leave off the ones you play most, say. A part that's off is off for everyone: your page looks the same to friends as it does to you, and they aren't sent the parts you turn off. They're all on to begin with, like the other sharing switches; hidden games are never shown, and games you added by hand are never named to friends. Settings → Friends → Your profile page has a row that opens your page. A friend's page, and the picture behind it, are kept in `~/.cache/plasma/friends` so you can look at them while they're offline, and a friend on a copy of Plasma from before this has an empty one.
- **What friends see:** the name you pick, your profile, what's on your profile page, that you're online, and the game you're playing. A switch turns the game off, and games you've hidden in the library are never mentioned. People who aren't in your list are told nothing.
- **No Plasma server.** Copies of Plasma talk to each other through [iroh](https://iroh.computer): the messages are encrypted end to end and carried by iroh's public relays. Plasma only uses the relays, never a direct connection, so friends don't learn your internet address. The relay can see that two computers are talking, not what they say.
- **Your account is a file:** `~/.config/plasma/friends-identity`. Copy it to another computer to be the same person there; anyone else who gets hold of it can be you, so keep it to yourself. Your list is in `~/.config/plasma/friends.toml`, your pictures (the background among them) in `~/.config/plasma/profile`, and the last profile each friend sent in `~/.cache/plasma/friends`.
- **Messages.** A friend's card has a box to send them a line of text, and shows the last few lines either of you said. They go straight to the friend's copy over the same encrypted link, only while you're both online, and nothing is kept once Plasma is closed. A friend on a copy from before messages existed can't get them, and their card has no box.
- **Games you both have.** A friend's card lists the games you have in common. For that, each copy tells friends which store games it has (not hidden ones, and not ones added by hand); the switch for it is under Settings → Friends.
- **News.** When a friend comes online or starts a game, a line says so at the foot of the window, and as a desktop notification if Plasma isn't the window in front. Friends who were already online when you started aren't announced. There's a switch for it under Settings → Friends.
- Turning friends off disconnects: nobody sees you and you see nobody. There's no "appear offline while still watching", because nothing in the middle could keep that promise.

## Themes

Click the settings button at the top right to pick a palette and a theme. **Palette** is the app's colours, each a row with its name and its colours in a row of overlapping circles: **Dark** (violet on near black, the one it starts with), **Light** (violet on white), **Coffee** (coffee browns, flat white with mocha) and **OLED** (violet on true black, with nothing of the game art showing through the page, for OLED screens). Click one to switch to it. A palette is light or dark throughout, so it takes the place of a colour scheme. The same page has **Reduce motion**, which turns the app's animations off: pages, covers, pop-ups and profile cards appear at once, nothing lifts under the pointer, and GIF pictures hold on their first frame. If the system itself has animations turned off, Plasma keeps them off too. Under it is **Animations when unfocused**: left on, GIF pictures and the video behind a profile page keep going while another window is in front; turned off, they wait on the frame they're at until Plasma is in front again, which saves processor time while you're in a game. Either way they stop while the window can't be seen at all. **Fold the sidebar** has it show only its icons until you point at it, when it slides out and pushes the page over, and back again once you've moved away (it stays out while a profile card or a menu from it is open). Your choices are saved in `~/.config/plasma/settings.toml`.

- **Default** is Plasma's own look, after Caelestia Shell: the frame goes all the way round the page, with the same big round corner at each of the page's four corners in flat Material You colours, in whichever palette you've picked. It always loads underneath the theme you pick, so a theme only has to change what it wants to look different.
- Your own themes are CSS files in `~/.config/plasma/themes`. The file name is the theme's name.

In the Theme section:

- **+** makes a new theme from a commented template and opens it in your editor. It lists the colour variables and every class you can style.
- The open-file button imports a `.css` file someone shared with you.
- The folder button opens the themes folder.

Plasma watches the active theme's file and restyles straight away each time you save it.

The template lists every class you can style: the window and backdrop, the sidebar, friends, profile cards and profile pages, the top bar, library cards, the game page, the store and the art frames. Colours come from libadwaita's CSS variables (`--accent-bg-color`, `--window-bg-color`, …), Material's other colours have theirs (`--surface-container`, `--primary-container`, `--secondary-container`, …), the frame has its own (`--frame-bg`, `--frame-border`, `--frame-field`, `--frame-card`, `--edge` for the border's width, `--frame-radius` for the page's corners), and so do the panels inside pages: `--glass-bg`, `--glass-border`, `--art-radius` and the two `--backdrop-tint-…` values that set how much of the art shows through.

## Windows

Plasma was written on and for Linux. There is a Windows build, but **it has never been started**: it was made with no Windows computer to try it on, so expect rough edges and say what breaks.

Whoever gets the Windows zip unpacks it and runs `Plasma.bat`. It needs 64-bit Windows 10 or 11.

What's different on Windows:

- **Steam** is found through the registry, or in Program Files. **Heroic**'s settings are read from `%APPDATA%\heroic`.
- **Running games** are spotted by a program running from the game's install folder, for Steam games too (Linux goes by Steam's own minder process). Closing one asks it nicely with `taskkill`, then forces it after five seconds.
- **Games you add by hand** take a program and arguments, with double quotes round anything with spaces, rather than a shell command. GameMode, MangoHud and Gamescope are Linux tools and aren't offered.
- Plasma's own files are in `%APPDATA%\plasma` (settings, themes, friends) and `%LOCALAPPDATA%\plasma` (cached art).
- Friends work across the two: someone on Windows and someone on Linux see each other.
